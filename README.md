# Marie-Gold — music

Stems and lyrics for every released song by Marie-Gold. One folder per song or project.

## Structure

```
songs-name/
  stems/        stems and full track (WAV)
  lyrics.csv    
  credits.yaml  
LICENCE.md      what you may do with these files
```

## How to download

The WAV files are stored with [Git LFS](https://git-lfs.com). Without it, you get small text files instead of the audio.

```bash
brew install git-lfs        # macOS — other systems: https://git-lfs.com
git lfs install             # once per computer
git clone https://github.com/marie-gold/music.git
```

Already cloned without Git LFS? Run `git lfs install && git lfs pull`.
